How it works

Three steps from "this looks off" to a full case file.

01

Paste the raw email

In Gmail: ⋮ → "Show original". In Outlook: "View message source". Copy everything — headers included — and paste it in. Nothing is forwarded anywhere; analysis runs on the server you're using.

02

Threadline investigates

It verifies SPF/DKIM/DMARC, extracts the true sender IP, hunts typosquats like 0ffice365, checks domain age via RDAP, and cross-references VirusTotal, AbuseIPDB, and URLhaus.

03

Read the verdict

A 0–100 risk score, every finding explained in plain language, the attack chain traced sender → link → landing page, and a defanged markdown report ready for a SOC or abuse desk.

The checks

What gets examined in every case.

Sender authentication

SPF, DKIM, and DMARC results; originating IP recovered from the Received chain.

Impersonation

Homoglyph typosquats, look-alike domains, display names claiming brands they don't own.

Link forensics

Punycode, @-tricks, shorteners, high-abuse TLDs, anchor text that lies about its destination.

Reputation

Domain age via RDAP, VirusTotal, AbuseIPDB, and URLhaus — free keys, all optional.

Attachments

Executable and macro-capable types flagged; SHA-256 recorded for every file.

History

Repeat offenders — the same sender or domain showing up across earlier cases.
